1. EXECUTIVE SUMMARY & CLINICAL OBJECTIVE
================================================================================
Pneumonia remains the single largest infectious cause of death in children under 
five globally. Conventional radiographic diagnosis relies on pediatric radiologists 
identifying subtle radiographic patterns such as patchy infiltrates, lobar 
consolidation, or interstitial reticular markings on anterior-posterior (AP) chest 
X-rays. High patient volumes, diagnostic fatigue, and scarcity of pediatric specialists 
in low-resource settings often delay critical treatment.

This project implements an end-to-end, clinically interpretable deep learning 
pipeline designed to:
  1. Accurately triage pediatric chest X-rays into NORMAL or PNEUMONIA.
  2. Maintain high diagnostic sensitivity (Recall = 94.36%) to minimize dangerous 
     false-negative triage outcomes.
  3. Demystify the "black box" deep neural network through Gradient-Weighted Class 
     Activation Mapping (Grad-CAM), generating an "RGB-like" thermal colormap 
     superimposed on anatomical structures to visually validate focal pulmonary 
     abnormalities.

2. NEURAL NETWORK ARCHITECTURE & MATHEMATICAL FORMULATION
================================================================================
2.1 Backbone Architecture: ResNet-18 (Deep Residual Learning)
The feature extractor is based on the ResNet-18 architecture (He et al., CVPR 2016).
Traditional deep convolutional networks suffer from the vanishing/exploding gradient 
phenomenon and degradation where training accuracy saturates and then rapidly drops.
ResNet resolves this using identity shortcut connections ("skip connections").

Mathematical Formulation:
For a stacked set of convolutional layers, let the target underlying mapping be H(x).
The stacked nonlinear layers are driven to approximate a residual function:
    F(x) = H(x) - x
The original function is recast as:
    H(x) = F(x) + x
where:
  - x is the input vector to the residual block.
  - F(x) represents the residual mapping to be learned (two 3x3 conv layers + BN + ReLU).
  - '+' denotes element-wise addition over the identity shortcut.

When input and output spatial dimensions or channel counts differ, a 1x1 convolution 
shortcut with stride 2 performs linear projection to match dimensions.

Layer Topology (18 Parameterized Layers):
  - Initial Convolution: 7x7 Conv, 64 filters, stride 2, padding 3
  - Batch Normalization + ReLU activation
  - Max Pooling: 3x3 kernel, stride 2, padding 1
  - Stage 1 (layer1): 2 BasicBlocks, 64 channels, stride 1 (output: 64 x 56 x 56)
  - Stage 2 (layer2): 2 BasicBlocks, 128 channels, stride 2 (output: 128 x 28 x 28)
  - Stage 3 (layer3): 2 BasicBlocks, 256 channels, stride 2 (output: 256 x 14 x 14)
  - Stage 4 (layer4): 2 BasicBlocks, 512 channels, stride 2 (output: 512 x 7 x 7)
  - Global Average Pooling (GAP): Reduces spatial dimensions from 7x7 to 1x1, producing 
    a 512-dimensional embedding vector invariant to spatial translations.

2.2 Classification Head
The default 1000-class ImageNet fully connected layer is replaced by a specialized 
clinical classification head:
  - nn.Dropout(p=0.5): Inverts co-adaptation by randomly zeroing 50% of the 512-D 
    features during training forward passes, mitigating overfitting.
  - nn.Linear(in_features=512, out_features=2): Projects the regularized latent representation 
    into 2 unnormalized class logits:
        z = [z_0, z_1]  where z_0 corresponds to NORMAL, z_1 corresponds to PNEUMONIA.

2.3 Transfer Learning Strategy
The convolutional weights are initialized from ImageNet-1K V1 (trained on 1,281,167 natural 
images across 1,000 categories). Transfer learning allows the lower convolutional layers 
to immediately leverage fundamental visual primitives (Gabor-like edge detectors, texture 
gradients, curves, corner junctions), while full fine-tuning with a calibrated learning 
rate allows intermediate and high-level representations to align specifically with lung field 
densities, costophrenic angles, and cardiac silhouettes.

The dataset consists of retrospective anterior-posterior (AP) chest radiographs of

4. FEATURE EXTRACTION, PREPROCESSING & DATA AUGMENTATION PIPELINE
================================================================================
4.1 Input Dimensionality & Grayscale Handling
Chest radiographs are single-channel grayscale transmissions of ionizing radiation 
absorbed by anatomical densities (air = radiolucent/black, bone/metal = radiopaque/white).
To leverage three-channel ImageNet-pretrained weights without architectural modification:
  - Each grayscale image is broadcast into 3 identical channels:
      I_3ch = [I_gray, I_gray, I_gray] using transforms.Grayscale(num_output_channels=3).

4.2 Channel Normalization (Z-Score Standardization)
Each channel is normalized using ImageNet population statistics:
    Mean (μ) = [0.485, 0.456, 0.406]
    Std  (σ) = [0.229, 0.224, 0.225]
For every pixel intensity x ∈ [0.0, 1.0]:
    x_norm = (x - μ_c) / σ_c
This zero-centers activations and equalizes variance across input dimensions, accelerating 
gradient descent convergence and preventing saturation.

4.3 Stochastic Data Augmentations (Training Split)
To prevent overfitting on the 5,216 training samples and encourage spatial/photometric 
invariance, the following stochastic transformations are applied on the fly:
  1. Scale & Crop: Resize to 244 x 244, followed by transforms.RandomCrop(224). Models 
     minor patient distance variations relative to the X-ray receptor plate.
  2. Bilateral Symmetry: transforms.RandomHorizontalFlip(p=0.5). Simulates symmetric 
     left-right lung anatomies.
  3. Patient Tilt Perturbation: transforms.RandomRotation(degrees=10). Accounts for 
     subtle patient rotation during emergency pediatric radiographic capture.
  4. Photometric Jitter: transforms.ColorJitter(brightness=0.2, contrast=0.2). Models 
     fluctuations in radiographic tube voltage (kVp), current-time product (mAs), 
     and differing digital radiography (DR) scanner hardware calibrations.

4.4 Evaluation & Inference Preprocessing (Deterministic)
Validation, testing, and production inference strictly utilize deterministic transforms:
  - Resize directly to (224, 224) via Lanczos interpolation.
  - Broadcast to 3 channels.
  - Convert to PyTorch Tensor [C, H, W] with range [0.0, 1.0].
  - Normalize with ImageNet μ and σ.

5. TRAINING ALGORITHMS, OPTIMIZATION & LOSS FORMULATION
================================================================================
5.1 Class Imbalance Mitigation: Dual-Level Strategy
Because the training set contains ~2.89x more Pneumonia images than Normal images, 
naive training would bias the gradient updates towards the majority class. Two 
complementary mechanisms are employed:

  Mechanism A: WeightedRandomSampler (Data Level)
    For each class c ∈ {0, 1}, class weights are computed as w_c = 1 / N_c.
    Each sample i is assigned weight W_i = w_{label(i)}. Mini-batches are drawn with 
    replacement using these probabilities, ensuring every mini-batch contains an equal 
    expected proportion of Normal and Pneumonia radiographs.

  Mechanism B: Weighted Cross-Entropy Loss (Objective Level)
    The loss function assigns penalty weights inversely proportional to class prevalence:
        L = - (1 / N) * ∑_{i=1}^N [ w_{y_i} * log( p_{i, y_i} ) ]
    where w_NORMAL = 1.0, w_PNEUMONIA = 1/3 (0.333), and p_{i, c} = softmax(z_i)_c.
    This heavily penalizes misclassifications of the minority (Normal) class.

5.2 Optimization Algorithm: Adam Optimizer
The network parameters θ are optimized using Adam (Adaptive Moment Estimation):
    m_t = β_1 * m_{t-1} + (1 - β_1) * g_t          (1st moment vector / momentum)
    v_t = β_2 * v_{t-1} + (1 - β_2) * g_t^2        (2nd moment vector / variance)
    m̂_t = m_t / (1 - β_1^t)                        (Bias-corrected 1st moment)
    v̂_t = v_t / (1 - β_2^t)                        (Bias-corrected 2nd moment)
    θ_t = θ_{t-1} - α * m̂_t / (sqrt(v̂_t) + ε) - α * λ * θ_{t-1}
Hyperparameters:
  - Base Learning Rate (α): 1e-4 (0.0001)
  - First Moment Decay (β_1): 0.9
  - Second Moment Decay (β_2): 0.999
  - Stability Epsilon (ε): 1e-8
  - Weight Decay (λ): 1e-4 (L2 weight regularization on all trainable weights)
  - Mini-Batch Size: 32

5.3 Dynamic Learning Rate Scheduling & Early Stopping
  - Scheduler: ReduceLROnPlateau monitoring validation accuracy.
      * Mode: 'max'
      * Factor: 0.5 (halves learning rate when validation accuracy stops improving)
      * Patience: 3 epochs
  - Early Stopping:
      * Patience: 4 epochs without improvement in validation accuracy.
      * Checkpoint mechanism: Saves model_state_dict and optimizer_state when 
        val_acc reaches a new historical peak.
      * Convergence: Stopped at Epoch 6 with best validation accuracy = 100.00%.

7. INTERPRETABILITY ENGINE: GRAD-CAM & "RGB-LIKE" PSEUDO-COLOR HEATMAP
================================================================================
7.1 Why Interpretability is Required
In medical imaging, deep neural networks are frequently criticized as opaque "black boxes."
A model might achieve high accuracy by learning spurious correlations (such as hospital 
scanner artifacts, patient positioning markers, or tube labels) rather than true lung pathology.
Gradient-Weighted Class Activation Mapping (Grad-CAM; Selvaraju et al., ICCV 2017) provides 
visual evidence of the anatomical areas that directly prompted the model's decision.

7.2 Mathematical Derivation of Grad-CAM
Let:
  - Y^c be the unnormalized logit score for target class c (e.g., Pneumonia).
  - A^k be the feature activation map of the k-th channel (k ∈ {1, ..., K = 512}) in the 
    target convolutional layer. The target layer is chosen as the final conv layer of 
    ResNet-18 (`model.layer4[-1].conv2`), which possesses the highest-level semantic 
    abstractions while retaining 7x7 spatial resolution.
  - A_{i, j}^k be the activation at spatial coordinates (i, j) where i, j ∈ {1, ..., 7}.

Step 1: Compute Gradients via Backward Pass
During a backward pass with the class logit score Y^c:
    ∂Y^c / ∂A_{i, j}^k is computed for all channels k and spatial locations (i, j).

Step 2: Global Average Pooling of Gradients (Neuron Importance Weights)
The importance weight α_k^c for channel k is computed by averaging gradients across 
the spatial dimensions:
    α_k^c = (1 / Z) * ∑_{i=1}^u ∑_{j=1}^v ( ∂Y^c / ∂A_{i, j}^k )
where Z = u * v = 7 * 7 = 49 is the spatial area of the feature map.
The weight α_k^c captures how influential feature channel k is in predicting class c.

Step 3: Weighted Linear Combination & Rectified Activation (ReLU)
The class activation map L_{Grad-CAM}^c is formed by summing all channels weighted by 
their importance, followed by a Rectified Linear Unit:
    L_{Grad-CAM}^c = ReLU( ∑_{k=1}^{512} α_k^c * A^k )

The ReLU operation is mathematically essential: it discards features that have a negative 
correlation with class c (i.e., features that contribute to predicting NORMAL or other 
classes), isolating solely those features that increase the probability of PNEUMONIA.

Step 4: Dynamic Range Normalization
The resulting 7x7 map is normalized into the unit interval [0.0, 1.0]:
    CAM_{norm} = (L^c - min(L^c)) / (max(L^c) - min(L^c) + ε)

7.3 The "RGB-Like" Pseudo-Color Heatmap Transformation
How does a 7x7 scalar activation grid become an intuitive, colorful "RGB-like" diagnostic image?

  Step A: Bilinear Spatial Upsampling
    The 7x7 matrix is rescaled to match the full 224x224 input image resolution:
        CAM_{224x224} = cv2.resize(CAM_{norm}, (224, 224), interpolation=cv2.INTER_LINEAR)

  Step B: Quantization & Jet Colormap Application
    The normalized float values [0.0, 1.0] are mapped to 8-bit unsigned integers [0, 255]:
        CAM_{uint8} = np.uint8(255 * CAM_{224x224})
    Next, OpenCV's JET colormap (`cv2.applyColorMap(CAM_{uint8}, cv2.COLORMAP_JET)`) 
    maps every scalar intensity into a 3-channel color triplet:
      - Deep Blue (RGB: ~0, 0, 128 to 0, 0, 255): Zero activation (healthy lung tissue, 
        trachea, mediastinum, outside chest wall).
      - Cyan / Green (RGB: ~0, 255, 255 to 0, 255, 0): Baseline and intermediate background 
        activations.
      - Yellow / Orange (RGB: ~255, 255, 0 to 255, 128, 0): Moderate localized concern.
      - Intense Red (RGB: ~255, 0, 0): Peak gradient concentration corresponding to 
        focal consolidation, lobar opacification, and bacterial/viral exudates.

  Step C: Color Space Correction (BGR to RGB)
    OpenCV functions produce byte buffers in BGR sequence. The map is converted to RGB:
        Heatmap_{RGB} = cv2.cvtColor(Heatmap_{BGR}, cv2.COLOR_BGR2RGB)

  Step D: Alpha-Weighted Blending (Superimposition)
    To maintain clear anatomical landmark visibility (ribs, clavicles, diaphragm, cardiac 
    border), the RGB heatmap is semi-transparently superimposed over the original 
    radiograph:
        Overlay_{RGB} = α * Heatmap_{RGB} + (1 - α) * Original_{RGB}
    with blending coefficient α = 0.45.
    Result: A rich, luminous pseudo-color RGB visualization that reveals exactly which 
    anatomic lung lobes or infiltration zones triggered the AI's diagnostic verdict.

8. PRODUCTION DEPLOYMENT & SERVING ARCHITECTURE (FASTAPI + STREAMLIT)
================================================================================
8.1 High-Performance FastAPI REST Backend (`api.py`)
  - Server: Uvicorn ASGI on host 0.0.0.0, port 8000.
  - Startup Hook: Preloads the PyTorch ResNet-18 model checkpoint once into GPU/MPS memory.
  - Endpoints:
      * GET  /          → Returns service health and supported diagnostic classes.
      * POST /predict   → Accepts multipart image uploads (JPEG/PNG), runs preprocessing, 
                          executes forward + Grad-CAM backward pass, and outputs a JSON payload:
                          - class_name ("NORMAL" or "PNEUMONIA")
                          - confidence (percentage, e.g., 98.4%)
                          - probabilities (distribution across both classes)
                          - gradcam_image (Base64-encoded PNG of the RGB thermal overlay)
                          - original_image (Base64-encoded PNG for client verification)
      * GET  /metrics   → Returns the active test set benchmarks and confusion matrix counts.

8.2 Streamlit Diagnostic Web Interface (`app.py`)
  - Clinician-facing interactive portal running on port 8501.
  - Features:
      * Seamless file uploader for DICOM-exported JPEG/PNG radiographs.
      * Side-by-side comparative inspection: Original Radiograph vs. Grad-CAM Overlay.
      * Real-time confidence meters and class probability distribution charts.
      * Interactive metrics dashboard displaying ROC curves, PR curves, and confusion matrix.
      * Comprehensive automated execution script (`start.sh`) running both services concurrently.
